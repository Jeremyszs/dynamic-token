# Legacy Tkinter Version Archive

This directory contains the original native Tkinter + Win32 GDI implementation of Dynamic Island HUD (`dynamic_island_hud.py`).

The application has been officially ported to **PySide6 + Qt Quick/QML** located under `app/`.

### Running the Legacy Tkinter HUD
To launch the legacy Tkinter implementation:
```bash
python legacy_tkinter/dynamic_island_hud.py
```
